# Project Skills

Repository-specific skills live here. They are intended for future agents that repeatedly work on this survey/reproduction project.

Available local skill:

- `survey-reproduction`: use for paper survey updates, source-ledger maintenance, OPSD reproduction planning, dataset setup, experiment logging, and presentation integration.

Suggested structure:

```text
agents/skills/<skill-name>/SKILL.md
agents/skills/<skill-name>/references/
agents/skills/<skill-name>/scripts/
```

Keep project skills small, explicit, and tied to this repository's real tools and checks.
